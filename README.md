# Классификатор ЕСКД

Сайт помогает подобрать децимальный номер ЕСКД через короткий диалог с вопросами.

## Как это работает

1. Вы отвечаете на вопросы в чате.
2. Система постепенно сужает круг вариантов.
3. В конце показывает подходящий децимальный номер, полное описание ветки и, если есть, изображение.
